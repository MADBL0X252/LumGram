# Bundled fonts

Eight unmodified variable TTF fonts are bundled locally. Each family’s SIL Open Font License and copyright notice is included alongside it. These fonts are distinct from the upstream extension assets and are used under their included font licenses.

| Family | Font file | Upstream source |
|---|---|---|
| Inter | `assets/fonts/inter.ttf` | https://github.com/google/fonts/tree/main/ofl/inter |
| Roboto | `assets/fonts/roboto.ttf` | https://github.com/google/fonts/tree/main/ofl/roboto |
| Nunito | `assets/fonts/nunito.ttf` | https://github.com/google/fonts/tree/main/ofl/nunito |
| Montserrat | `assets/fonts/montserrat.ttf` | https://github.com/google/fonts/tree/main/ofl/montserrat |
| Outfit | `assets/fonts/outfit.ttf` | https://github.com/google/fonts/tree/main/ofl/outfit |
| Source Sans 3 | `assets/fonts/sourcesans3.ttf` | https://github.com/google/fonts/tree/main/ofl/sourcesans3 |
| Lora | `assets/fonts/lora.ttf` | https://github.com/google/fonts/tree/main/ofl/lora |
| JetBrains Mono | `assets/fonts/jetbrainsmono.ttf` | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

Fonts retain native text sizes and requested weights. Browser-generated italics may be used; no separate italic files are bundled. Glyphs not provided by a selected font use normal browser fallback. Device font files are not read, copied, uploaded, or bundled; only the chosen family name is stored.
